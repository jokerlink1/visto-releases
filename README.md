# VISTO — avaliação de atitudes em sala de aula

Página do programa: **https://jokerlink1.github.io/visto-releases/**

Descarregue a versão mais recente em **[Releases](../../releases/latest)**:

- **VISTO_Pf_Setup.exe** — VISTO (no seu computador)
- **VISTO_Ag_Setup.exe** — VISTO Ag (com conta no servidor do agrupamento)
- **VISTO_Pf.apk / VISTO_Ag.apk** — apps Android de consulta

Depois de instalado, o programa **atualiza-se sozinho**: ao abrir (e de 6 em 6 horas) verifica se há versão nova
e instala-a, sem mexer nos seus dados. Pode desligar em Definições → Dados → Atualizações.

O Windows pode avisar que o programa «não é reconhecido» (não está assinado digitalmente):
«Mais informações» → «Executar mesmo assim».
