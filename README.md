# VISTO — da aula à nota, com critério

Página do programa: **https://jokerlink1.github.io/visto-releases/**

Avaliação aula a aula, elementos de avaliação por domínios, subdomínios e critérios, autoavaliação reporte a reporte,
grelha de avaliação, pauta e relatório final — de acordo com o referencial de avaliação do agrupamento.
Ensino básico (níveis 1–5), secundário e profissional (0–20, módulos e UFCD).

Descarregue a versão mais recente em **[Releases](../../releases/latest)**:

- **VISTO_Pf_Setup.exe** — VISTO Pf, para o professor (os dados ficam no seu computador)
- **VISTO_Ag_Setup.exe** — VISTO Ag, para o agrupamento (conta no servidor da escola, vários computadores)
- **VISTO_Pf.apk / VISTO_Ag.apk** — apps Android

Depois de instalado, o programa **atualiza-se sozinho**: ao abrir (e de 6 em 6 horas) verifica se há versão nova
e instala-a, sem mexer nos seus dados. Pode desligar em Definições → Dados → Atualizações.

O Windows pode avisar que o programa «não é reconhecido» (não está assinado digitalmente):
«Mais informações» → «Executar mesmo assim».

Este repositório distribui apenas os instaladores e as apps.
